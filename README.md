# AN24 ONE Cloud v0.1

Primera versión navegable del CRM cloud de AN24.

Incluye:
- Login demostración
- Dashboard
- Clientes y ficha 360º
- Agenda
- Oportunidades
- Productos
- Comerciales
- Servicios AN24
- Documentos
- Informes
- Configuración
- Esquema inicial de Supabase

## Instalación

```bash
npm install
npm run dev
```

## Publicación

Sube los cambios a la rama `main` del repositorio `an24-one-cloud`. Vercel desplegará automáticamente.
