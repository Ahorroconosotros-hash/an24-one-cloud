AN24 ONE · ACTIVAR GUARDADO DE CLIENTES

1) En Supabase abre SQL Editor y ejecuta:
   supabase/sprint2_clientes.sql

2) Crea un archivo llamado .env.local en la raíz del proyecto con:
   SUPABASE_URL=https://zddsrtbtlmaetznubtwi.supabase.co
   SUPABASE_SERVICE_ROLE_KEY=PEGA_AQUI_TU_SERVICE_ROLE_KEY

La Service Role Key se encuentra en Supabase > Project Settings > API Keys.
No publiques ni compartas el archivo .env.local.

3) Arranca el proyecto:
   npm install
   npm run dev

FLUJO IMPLEMENTADO
- Valida obligatorios.
- Impide DNI/CIF duplicado.
- Guarda el cliente en clients.
- Guarda el responsable de empresa en contacts.
- Guardar cliente redirige a /clientes/[id].
- Guardar e ir a contratación redirige a /servicios?cliente=[id].
- Muestra errores reales de Supabase en pantalla.
