# ONE · Patrón maestro de oportunidades v0.8.0

Energía, Seguros y Alarmas comparten desde esta versión la misma gramática visual: cabecera, tarjetas, secciones, campos, documentos, notas y acciones. Cada línea de negocio conserva únicamente sus datos específicos.

Principio: **menos picar, más vender**. Gestión es la fuente de proveedores, productos, características, precios, IVA y promociones. Las oportunidades reutilizan esos datos y conservan snapshots para trazabilidad.

## Alarmas
Pack + productos adicionales multilínea, características, precio, promoción oficial, IVA, fechas de instalación/activación, previsión de comisión, documentos, notas y oferta estructurada.

## Seguros
Misma piel y flujo, adaptado al riesgo y a los datos específicos de cada modalidad.

## Energía
Misma piel y flujo, adaptado a suministro, CUPS, producto, dirección y activación.
